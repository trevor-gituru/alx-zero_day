# ALX Zero Day Project

Welcome to the ALX Zero Day repository, the foundational step in my software engineering journey with ALX. This repo contains a series of hands-on tasks designed to build mastery in essential tools and concepts including the Linux shell, text editors, and version control systems.

## Directory Overview

This project is divided into several directories, each representing a core area of learning:

---

### 📁 [0x00-shell_navigation](./0x00-shell_navigation)

- Learn to navigate the Unix/Linux file system using basic Shell commands like pwd, ls, cd, etc.
- Topics: file path resolution, hidden files, listing with flags, navigating up and down directory levels.
- Skills: Efficient movement in the terminal, understanding system structure.

🧭 [View README](./0x00-shell_navigation/README.md)

---

### 📁 [0x01-emacs](./0x01-emacs)

- Introduction to the Emacs editor: starting, navigating, editing, and exiting.
- Tasks involve using keyboard shortcuts, opening/saving files, switching buffers, and exiting cleanly.
- Builds foundational skills for advanced coding workflows in Emacs.

📝 [View README](./0x01-emacs/README.md)

---

### 📁 [0x02-vi](./0x02-vi)

- Dive into vi (Vim), another powerful command-line text editor.
- Learn command vs insert mode, cutting/pasting lines, searching, undoing, and navigating within lines.
- Reinforces key modal editing concepts for productivity in terminal environments.

📝 [View README](./0x02-vi/README.md)

---

### 📁 [0x03-git](./0x03-git)

- Version control using Git: repository initialization, status checks, committing, pushing to remote, etc.
- Also covers collaboration using GitHub and basic branching.
- Essential for teamwork and maintaining robust codebases.

🔗 [View README](./0x03-git/README.md)

---
